# Product Baseline

## Priority Rule

If this file, `README.md`, and any historical `docs/` content differ from the latest internal product document shared by the team, the internal product document is the source of truth.

This note exists because the repository was initialized before the latest product scope was fully written down.

## MVP Scope in This Scaffold

The current scaffold covers these baseline capabilities:

- register, login, logout, current user
- personal profile editing and profile page
- module entry pages for dating, teammate matching, forum, and admin
- teammate post creation, application flow, and admin visibility
- dating profile, preference, candidate, and mutual-interest skeleton
- forum posts, comments, likes, and search skeleton
- moderation report and block skeleton

## Deferred from the First Scaffold

- campus verification by school email
- SMS login
- production-grade recommendation ranking
- full realtime chat implementation
- credit score and trust model
- favorites and collections
